🎯 ¿QUÉ TIENES AQUÍ?

   Un proyecto completo de Python que implementa un sistema de restaurante
   con capacidades de venta de productos, gestión de usuarios y persistencia
   de datos en archivos JSON.

   ✨ LO MÁS IMPORTANTE:
   • Nuevo modelo: Clase VENTA que relaciona Usuario + Producto
   • Nueva operación: VENDER PRODUCTO (con validaciones)
   • Nueva consulta: VER VENTAS DE UN USUARIO
   • Persistencia: 3 archivos JSON (productos, usuarios, ventas)
   • Documentación: 7 archivos guía para cada aspecto

✨ CARACTERÍSTICAS PRINCIPALES

   1️⃣  NUEVO: Clase Venta
       Relaciona un Usuario con un Producto que compró.
       Ejemplo: Juan compró una Hamburguesa (2 unidades)

   2️⃣  NUEVO: Operación Vender
       • Valida que el usuario exista
       • Valida que el producto exista
       • Valida que la cantidad sea válida
       • Valida que haya stock suficiente
       • Si todo es OK: registra la venta y disminuye stock

   3️⃣  NUEVO: Consultar Ventas de Usuario
       Muestra todas las compras que hizo un usuario.
       Ejemplo: Ver todas las compras de Juan

   4️⃣  PERSISTENCIA COMPLETA
       • productos.json - Productos con su stock actualizado
       • usuarios.json - Usuarios registrados
       • ventas.json - Historial de todas las ventas

❓ PREGUNTAS FRECUENTES

   P: ¿Necesito instalar algo?
   R: No. Solo Python 3.7+ (ya incluido en Windows)

   P: ¿Dónde se guardan los datos?
   R: En restaurante_app/datos/ (archivos JSON)

   P: ¿Los datos se pierden al cerrar?
   R: No. Se guardan automáticamente en JSON y se recuperan al abrir

   P: ¿Puedo vender más de lo que hay en stock?
   R: No. El sistema rechaza la venta y muestra un mensaje de error

   P: ¿Qué cambió respecto a Semana 10?
   R: Se agregaron: Venta, usuarios persistidos, ventas persistidas

   P: ¿Cómo lo subo a GitHub?
   R: Lee INSTRUCCIONES.md (sección "Para GitHub")
