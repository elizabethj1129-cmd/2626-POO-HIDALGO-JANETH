## 📊 Lo que Hace el Programa

✓ Registra productos con stock  
✓ Registra usuarios  
✓ Realiza ventas (relaciona usuario + producto)  
✓ Controla stock automáticamente  
✓ Guarda todo en archivos JSON  
✓ Recupera datos al reabrir

## 🎯 Requisito Clave: Semana 11

**Operación de Venta:**
1. Usuario compra
2. Sistema valida stock
3. Se registra la venta
4. Stock disminuye
5. Se guardan productos.json y ventas.json

**Consulta de Ventas:**
- Ver todas las compras de un usuario
- Muestra detalles de cada producto
